# Careless Responding Simulations

This repository contains R scripts illustrating how careless responding and the handling of detected careless responses can affect statistical estimation. The simulations distinguish the true response state from an imperfect observed detector and compare naive analysis, oracle handling based on the true response state, and practical handling based on the detector.

## Notation and coding

For respondent \(i\):

- \(R_i^{CR}=1\) denotes attentive responding.
- \(R_i^{CR}=0\) denotes careless responding.
- \(V_i^*\) denotes the target response that would be observed under attentive responding. The simulation-specific target response is denoted by either \(X_i^*\) or \(Y_i^*\).
- \(U_i\) denotes a response generated by the careless-response process.
- \(D_i\) denotes an imperfect observed proxy for \(R_i^{CR}\).

The observed response follows

\[
V_i^{\mathrm{obs}}
=
R_i^{CR}V_i^*
+
(1-R_i^{CR})U_i.
\]

Thus, the observed response equals the target response when \(R_i^{CR}=1\) and the carelessly generated response when \(R_i^{CR}=0\). Note that the coding may be counterintuitive: a value of one indicates attentive rather than careless responding.

## Files

### `Simulation1.R`

Simulation 1 examines bias in estimating the mean of the target-response distribution under three careless-response mechanisms:

- CRCR: the response-state indicator is independent of the target response.
- CRAR: an observed covariate is a common cause of the target response and the response-state indicator.
- CRNAR: the response-state indicator depends directly on the target response.

The careless response is generated as

\[
U_i\sim\mathcal{N}(\mu_U,1),
\]

where \(\mu_U=0\) represents an unbiased careless-response distribution and \(\mu_U=1\) represents a systematically shifted careless-response distribution. This stylized manipulation contrasts a condition in which the careless-response distribution has the same mean as the target-response distribution with a condition in which careless responding systematically shifts the observed-response distribution. It is not intended to reproduce a specific behavioral response pattern such as straightlining.

Under CRCR, the target response is generated as

\[
X_i^*\sim\mathcal{N}(0,1),
\]

and the response-state indicator is generated independently as

\[
R_i^{CR}\sim\mathrm{Bernoulli}(0.5).
\]

Under CRAR, a binary covariate is first generated as

\[
C_i\sim\mathrm{Bernoulli}(0.5).
\]

The target response is then generated as

\[
X_i^*
=
0.5(C_i-0.5)+\varepsilon_{Xi},
\qquad
\varepsilon_{Xi}\sim\mathcal{N}(0,0.9375).
\]

This parameterization gives \(X_i^*\) a marginal mean of zero and a marginal variance of one, although its marginal distribution is a mixture of two conditional normal distributions. The probability of attentive responding is

\[
\Pr(R_i^{CR}=1\mid C_i)
=
\frac{\exp(0.6C_i)}
{1+\exp(0.6C_i)}.
\]

Thus, \(C_i\) is a common cause of \(X_i^*\) and \(R_i^{CR}\).

Under CRNAR, the target response is generated as

\[
X_i^*\sim\mathcal{N}(0,1),
\]

and the probability of attentive responding depends directly on the target response:

\[
\Pr(R_i^{CR}=1\mid X_i^*)
=
\frac{\exp(0.5X_i^*)}
{1+\exp(0.5X_i^*)}.
\]

In the CRAR and CRNAR conditions, the logistic transformation ensures that the generated response-state probabilities lie between zero and one. The coefficients governing the response-state mechanism are held constant across the \(\mu_U=0\) and \(\mu_U=1\) conditions so that the manipulation changes only the careless-response distribution.

The observed response is generated as

\[
X_i^{\mathrm{obs}}
=
R_i^{CR}X_i^*
+
(1-R_i^{CR})U_i.
\]

Each condition uses \(n=30{,}000\) observations and 1,000 Monte Carlo replications. The script compares the following estimators:

1. the mean of the uncontaminated target responses;
2. the naivee mean based on all observed responses;
3. the mean after oracle deletion using the true response state; and
4. under CRAR, a covariate-adjusted estimator standardized over the marginal distribution of \(C_i\).

The script creates the following LaTeX/TikZ figures:

- `figure_CRCR.tex`
- `figure_CRAR.tex`
- `figure_CRNAR.tex`

### `Simulation2.R`

Simulation 2 illustrates the consequences of collider selection when the careless-response indicator also determines which response process contributes to the observed outcome. The predictor is generated as

\[
X_i\sim\mathcal{N}(0,1),
\]

and the attentive outcome is generated as

\[
Y_i^*
=
0.4X_i+\varepsilon_{Yi},
\qquad
\varepsilon_{Yi}\sim\mathcal{N}(0,1).
\]

A latent response-state propensity is generated as

\[
P_i
=
0.5Y_i^*
+
0.4X_i
+
\varepsilon_{Ri},
\qquad
\varepsilon_{Ri}\sim\mathcal{N}(0,1),
\]

with \(R_i^{CR}=1\) when \(P_i>0\). Here, \(P_i\) is a latent propensity rather than a probability. The careless response is generated as

\[
U_i\sim\mathcal{N}(1,1).
\]

The observed outcome is

\[
Y_i^{\mathrm{obs}}
=
R_i^{CR}Y_i^*
+
(1-R_i^{CR})U_i.
\]

Because both \(X_i\) and \(Y_i^*\) affect \(R_i^{CR}\), the response-state indicator is a collider. Retaining all observations preserves contamination from \(U_i\), whereas restricting the analysis to \(R_i^{CR}=1\) conditions on the collider.

The simulation uses \(n=30{,}000\) observations and 1,000 Monte Carlo replications. It creates `figure_Collider.tex`.

### `Simulation3.R`

Simulation 3 examines bias arising from the handling strategy and from imperfect detection of the true response state. Unlike an earlier version of the simulation, potential outcomes are not generated because the purpose is to evaluate the bias decomposition rather than identify a potential-outcome estimand.

A binary predictor is generated as

\[
X_i\sim\mathrm{Bernoulli}(0.5),
\]

and the uncontaminated target outcome is generated directly as

\[
Y_i^*
=
X_i+\varepsilon_{Yi},
\qquad
\varepsilon_{Yi}\sim\mathcal{N}(0,1).
\]

The population coefficient of \(X_i\) is therefore one. Careless responses are generated as

\[
U_i\sim\mathrm{Uniform}(-1,1).
\]

Two response-state mechanisms are considered. Under CRCR,

\[
R_i^{CR}\sim\mathrm{Bernoulli}(0.5),
\]

independently of \(X_i\) and \(Y_i^*\). Under CRNAR, the probabilities of attentive responding are

\[
\Pr(R_i^{CR}=1\mid Y_i^*>0)=0.7
\]

and

\[
\Pr(R_i^{CR}=1\mid Y_i^*\leq 0)=0.1.
\]

The observed outcome is generated as

\[
Y_i^{\mathrm{obs}}
=
R_i^{CR}Y_i^*
+
(1-R_i^{CR})U_i.
\]

An imperfect detector \(D_i\) is generated conditional only on the true response state:

\[
\Pr(D_i=1\mid R_i^{CR}=0)=0.2
\]

and

\[
\Pr(D_i=1\mid R_i^{CR}=1)=0.7.
\]

Under the stated coding, \(D_i=1\) indicates classification as attentive. The simulated detector therefore correctly classifies an attentive response with probability 0.70 and correctly classifies a careless response with probability 0.80.

The script compares:

1. naive analysis using all observed outcomes;
2. oracle deletion using the true response state \(R_i^{CR}\); and
3. practical deletion using the imperfect detector \(D_i\).

The practical estimator's bias is decomposed as

\[
\text{total practical bias}
=
\text{handling-strategy bias}
+
\text{misclassification bias}.
\]

Handling-strategy bias is the difference between the oracle-deletion estimate and the coefficient estimated from the uncontaminated outcomes in the corresponding replication. Misclassification bias is the additional difference produced by replacing the true response state with the imperfect detector.

Each condition uses \(n=30{,}000\) observations and 1,000 Monte Carlo replications.
